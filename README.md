## &nbsp;✦ About

> <b>Fake World</b> — building real things in it.

- 🛠️ **What I do** — 嵌入式与 MCU 指令级仿真（Renesas RH850 → WASM），中日 NLP 与平行语料，以及把一切能 self-host 的服务都搬回家的折腾。
- 🌱 **Currently exploring** — Rust + WASM 交叉编译链路、CPU 仿真器的异常/FPU 路径、语音克隆（RVC）与 TTS 工具链。
- 🧰 **How I work** — Python 打底，Rust / Go / C 按需深入；zsh + polybar 的终端流；Fedora KDE 桌面。
- ☕ **Ask me about** — 自托管栈（DNS / 反代 / 文件同步 / PAM）、OpenWrt、车载电子（AUTOSAR / CAN / ESP32-CAN）、日语学习工具。
